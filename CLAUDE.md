# Instructions for AI coding assistants

- Commits must be authored and committed as the repo owner's git identity only.
- Never add `Co-Authored-By`, `Claude-Session`, "Generated with" or any AI attribution lines to commit messages or PR descriptions.
- Do not change `git config user.name` / `user.email` to an AI identity.
- AI use is declared once in the project submission, not in commit history.
